# 智慧图书馆微服务管理系统设计说明

## 1. 项目定位

本系统面向高校图书馆，覆盖系统管理员、图书管理员和读者三类角色。系统不仅提供图书信息的增删改查，还实现借阅、归还、续借、预约、逾期罚款、借阅规则和统计分析等相互关联的业务。

## 2. 技术架构

- 前端：Vue 3、TypeScript、Element Plus、ECharts、Axios、Vue Router。
- 后端：Spring Boot 3、Spring Cloud Gateway、MyBatis-Plus、MySQL。
- 微服务：网关、认证、图书、读者、流通、系统、统计服务。
- 基础设施：Nacos、Redis、Nginx、Docker Compose。

前端请求首先进入网关。网关校验JWT并将用户身份传递给业务服务，再根据请求地址路由到具体微服务。各微服务注册到Nacos，可以独立构建、部署和扩展。

## 3. 核心业务

### 借阅

1. 根据读者ID检查当前借阅数量。
2. 检查是否达到该读者的最大借阅上限。
3. 根据馆藏条码锁定一本状态为 `AVAILABLE` 的副本。
4. 创建借阅记录，计算应还时间。
5. 将副本改为 `BORROWED`，同时减少图书可借数量。

以上操作使用数据库事务，任意一步失败都会回滚，防止出现“生成借阅记录但库存没有减少”的数据不一致。

### 归还

1. 检查借阅记录是否仍处于借阅中。
2. 写入实际归还时间。
3. 判断是否超过应还时间。
4. 恢复馆藏副本状态和图书可借数量。
5. 如果逾期，按照逾期天数生成罚款记录。

### 续借

只有未归还、未逾期且没有超过最大续借次数的图书可以续借。每次续借会增加续借次数并延长应还日期。

### 预约

同一读者不能重复预约同一本图书。预约时按照当前等待人数生成排队序号，取消预约后记录仍然保留，用于业务追踪。

## 4. 多表查询

- 图书查询连接 `book`、`book_category`、`publisher` 三张表。
- 读者查询连接 `reader`、`sys_user` 两张表。
- 借阅查询连接 `borrow_record`、`book`、`reader`、`sys_user`、`book_copy` 五张表。
- 分类统计连接 `book_category` 和 `book` 两张表。

这些查询使用MyBatis注解SQL完成，满足课程要求中的多表关联和模糊查询。

## 5. 界面清单

系统包含登录、数据总览、图书管理、分类管理、读者管理、借阅管理、预约管理、公告管理、借阅规则、用户管理和个人中心共11类独立页面。页面统一采用深蓝和图书馆绿色视觉体系，包含响应式布局、状态标签、表格、对话框、数据卡片和ECharts图表。

## 6. 创新点

1. 对核心业务进行微服务拆分，通过Nacos注册、网关路由和独立容器实现模块解耦。
2. 使用Docker Compose统一启动数据库、注册中心、前端和全部后端服务。
3. 使用JWT实现无状态登录认证，并在网关统一完成身份校验。
4. 借阅、归还采用事务和行锁保护馆藏状态，增强系统健壮性。
5. 使用ECharts展示借阅趋势、分类分布和热门图书排行。
